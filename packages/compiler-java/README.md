# Java pipeline

This package uses a real JDK 21 toolchain. `javac` performs lexical, syntax, semantic, and type analysis and generates JVM bytecode; `javap -c` supplies the inspectable Java-specific bytecode IR; `jar` produces the final JVM artifact. JDK constant folding is observable in the bytecode representation. This package does not claim native machine-code generation.

`compileJava(source, sourceName?)` compiles a single source file, including packages, public classes, records, enums, and interfaces. Optional source names are safe relative `.java` paths (for example `demo/App.java`), with case-insensitive extension acceptance and lowercase `.java` normalization only for the internal javac filename. The returned `sourceName` preserves the supplied display name. Otherwise the top-level public type determines the filename. `generatedSource` is exactly the source passed to javac. Class artifact keys preserve package paths, including Unicode names.

JAR eligibility comes from compiled public static `void main(String[])` signatures, including varargs and main methods inherited from compiled superclasses. `jar.runnable` and optional `jar.mainClass` describe the actual manifest. A source without an eligible main produces a library JAR. javap inspection includes all emitted classes. Diagnostics contain real English javac messages and relevant symbol/type details, line and caret column when available, and generic `JAVA_COMPILER_ERROR` / `JAVA_COMPILER_WARNING` codes. Temporary source paths and compiler debug keys are excluded from messages.

Annotation processing is disabled, ambient project class/source paths are excluded, javac heap is limited to 256 MB, input to 1 MB, emitted classes to 256 / 8 MB, JAR to 8 MB, captured tool output to 8 MB per tool, and compilation tools share a 30-second deadline. These limits do not provide operating-system isolation. Arbitrary submitted programs are never executed by this package; trusted test fixtures execute only to verify artifacts. External superclass entrypoints and Java preview features are not enabled.
